# Deliver requested artifacts

At intake, reuse context to establish project/repository grouping, principal
outputs, annex treatment, format, destination and requested recipient access.
Working specialist reports do not automatically become separately published
documents. Preserve explicit grouping and keep useful evidence linked.

Use the actual format/provider owner for external delivery within existing
authorization. Before promising an action, verify its supported object/action
and prerequisites separately: create, convert, move, share file and share folder.
Tool discovery or upload success does not establish a sharing capability.
An unavailable requested action stays specifically pending; do not silently
substitute a different grouping or grant broader access.

After delivery, read back the actual result:

- Content, quantities/tables, conditions, links and meaningful structure survived.
- Returned URL, format/MIME, parent/folder and destination match the request.
- Effective requested recipient permissions apply to the intended object.

Successful file sharing does not prove folder access. If folder sharing is
unsupported, retain that limit and verify any independently authorized document
delivery; provide the requested folder link directly with its access state.
If a tool cannot inspect effective access, identify that missing observation
rather than claiming sharing is verified. Reuse current content/review evidence;
conversion or packaging alone does not require another full analysis.
