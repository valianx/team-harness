# Specialist coordination

Give a specialist a bounded objective, owned files or modules, relevant source
links, constraints and expected evidence. Include the repository/worktree and
reviewed revision when identity matters. Share enough context to work correctly
without copying every document into the prompt.

Coordinate overlapping edits and Git operations. Tell each worker about other
active owners and preserve their work. Reuse a native agent session for related
follow-up work when its context remains useful.

A specialist returns the result, changed paths, checks, findings, limitations and
any decision the coordinator must make. The coordinator integrates those facts
into the task. Native runtime permissions govern tool use; no TH capability lease
or authority envelope is required.
