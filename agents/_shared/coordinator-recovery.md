# Coordinator recovery

## Operational repair in every posture

Diagnose and repair operational failures before reporting a blocked objective.
Resolve stale paths, tools or dependencies and verify the repair. Reuse existing
authorization when deliverable and effect are unchanged; native permissions
still apply. Prefer isolated environment repair over changing product dependencies.

Preserve successful work. Change approach or evidence before repeating an action
that failed for the same cause. Do not invent missing evidence or silently expand
scope. Report the actual unresolved condition and useful attempted remedies.

## Activated pipeline

Read the existing plan, tasks and evidence. Confirm an overlapping writer has
stopped before reassignment. Continue a useful native session or replace one
whose context is unsuitable. Historical log corruption is an evidence limitation,
not a reason to erase progress or demand administrative closure. Use relevant
checks and independent advice after corrections; no lease or classifier controls
the next action.
