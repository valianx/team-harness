# Recovering work

Diagnose the concrete cause of an interruption, preserve completed work, and
continue from current repository state and available results. Repair missing
paths, tooling or ordinary integration problems within the authorized objective
and native permissions.

Reuse useful agent context and evidence. Choose a different approach when a
failed attempt reveals that the original approach will not work. Ask the
operator only when a necessary decision or capability is missing. Report what
is known, what remains uncertain, and the next action.
