# Observability

Retain a concise plan, task progress, decisions, findings and check results in
the selected workspace. Native runtime telemetry may add useful facts; TH does
not require remote Memory MCP or flow telemetry. Missing counters are unknown,
not failure or permission to continue. Read historical event logs and summaries
when present; do not fabricate them or create mandatory duplicate journals.
Optional trace/snapshot hooks need the exact selected TH_WORKSPACE binding.
