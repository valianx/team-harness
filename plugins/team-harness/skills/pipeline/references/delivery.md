# Publication

Use [the shared Publication phase](../../spec/references/development-phases.md)
with the existing evidence and requested endpoint. Local delivery and PR
preparation need no outward publication. Merge remains separately authorized.

Use the installed create-pr skill to prepare and publish authorized work.
Inspect actual checks and outstanding findings, include completed OpenSpec
archive, and preserve applicable review evidence. Main normally executes this
checkpoint; an assigned delivery specialist can use the same method and endpoint.
Follow create-pr's native identity and existing-PR checks once. Missing legacy
reports do not require another acceptance matrix or permission record. Recover
relevant context, renew affected evidence after changes and report actual limits.
Report observed CI and merge state without restarting completed validation.
