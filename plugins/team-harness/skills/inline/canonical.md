
# Inline preference

Interpret `on`, `off` or `status`; bare invocation means `on`. Main records
the preference in conversation and reports it concisely. It creates no pipeline
state and does not replace the native general agent.

This is a working preference, not authorization to bypass native permissions.
Use bounded delegation and independent advice when useful within the request;
honor an explicit preference to do the work directly. Use the shared workspace
when retained context helps. A change of method preserves existing useful work.
