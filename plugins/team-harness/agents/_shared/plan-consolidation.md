# Plan and result consolidation

Use OpenSpec for durable intent, scenarios and work tasks. Keep a concise plan
that links those sources and explains the approach, ownership, decisions and
progress. Update it when the work changes rather than generating a duplicate
acceptance schema.

Combine specialist findings with actual code and test evidence. Resolve
contradictions in the context of the operator's objective. The coordinator
owns the combined result and can update task progress after verification.
