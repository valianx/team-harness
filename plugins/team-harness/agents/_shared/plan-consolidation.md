# Plan and result consolidation

OpenSpec owns written intent, scenarios, design and tasks. The workspace plan
summarizes outcome, scope, approach, risks, decisions and links. It is not a second
specification; update it as work changes without an identity ceremony.

Main integrates results against actual changes and evidence. Assign an owner
for shared artifacts. Specialists may author assigned OpenSpec or workspace
artifacts when their role permits it.

## Write-tool discipline

Use native edit tools within assigned scope and preserve unrelated work.

## Write-scope on the plan set (closed list)

Agree ownership for proposal, specs, design and tasks. A scope change calls for
a real decision; ordinary authorized updates need no extra TH permission.
