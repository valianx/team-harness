# Recoverable progress

Keep a concise workspace note when the task needs continuity. Include objective,
repository/worktree/branch, source links, completed tasks, checks and findings,
active ownership, unresolved choices and the next useful action.

Verify saved facts against the current repository and available results when
resuming. Old state files and control logs can explain prior work but do not
authorize new actions. Preserve them as history instead of reconstructing the
retired control plane.
