# Connected findings

## Cross-check definition

When a suggested change removes a check or expands reachable behavior, compare
it with other findings about that path or its consumers. Assess related risks
together so that resolving one concern does not introduce or hide another.

For a concrete connection, explain the affected path, the related finding and
the consequence for the proposed correction. Main decides how to address it
using the full task context. Unrelated style comments need no such analysis;
do not invent a connection or require a separate report.
