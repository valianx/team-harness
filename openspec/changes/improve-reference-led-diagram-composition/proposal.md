## Why

Issue #719 records a real diagramming session that required about an hour of operator corrections before an editable Excalidraw reference became reusable. Current instructions can contradict approved component-card compositions, while React Flow shares ports across relationships and its checks do not establish practical visual readability.

## What Changes

- Carry approved composition preferences into both diagram skills and the diagrammer role; keep explicit engine requests authoritative and Excalidraw-first scoped to the selected workflow.
- Support native editable arrows, reciprocal labels, current-scene preservation and editor-verified exports through an identified compatible Excalidraw editor/renderer.
- Give React Flow relationships optional semantic interaction classes, stable side-specific ports and separate slots; evaluate routes together and retain bounded exploration evidence.
- Make the standalone canvas fill its host window and reveal upper/lower controls from their respective borders, preserving keyboard, popup and touch access.
- Validate the operator's actual source case and reference visually, separately from mechanical and source-fidelity checks.
- Validate the same case in bounded paired rounds before PR creation: retain the failed C1 and C3 pairs, correct their demonstrated native-visibility and supporting-corridor causes, then run one final pair against the corrected candidate with identical inputs and no coordinator feedback.

## Capabilities

### New Capabilities

- `reference-led-editable-diagrams`: contextual native Excalidraw composition, safe revision and faithful editor/export delivery.

### Modified Capabilities

- `source-driven-architecture-diagrams`: reference-led visual quality, relationship-specific routing, presentation controls and independent consumer validation.

## Impact

Canonical diagram skills/references, diagrammer guidance, React Flow starter/validation, a bounded native Excalidraw verification path, focused maintained cases, generated runtime projections and release metadata. Live trial inputs, generated artifacts, native usage and assessments remain outside tracked product files.

## Non-Goals

Universal palettes, mandatory two-engine workflows, fixed coordinates for arbitrary graphs, topology deletion to improve scores, a replacement drawing editor, automatic migration of existing consumer projects, unrestricted model trials or personal installation. The operator authorized publication and merge only after the objective is demonstrated.
