# Make review evidence reliable and advisory

## Why

Review consolidation can discard findings and preparation mutates tracked ignore rules. Spec routing and security classification also impose TH authorization that the native runtime already owns.

## What Changes

- security-classification-floor: keep classification as advice and property-based closure
- spec-direct-lane: allow bounded native delegation and useful reviews without mandatory escalation

## Capabilities

### Modified Capabilities

- security-classification-floor: keep classification as advice and property-based closure
- spec-direct-lane: allow bounded native delegation and useful reviews without mandatory escalation
- guided-lane-verification: preserve anchored review evidence without routing or permission gates

## Impact

Canonical roles, skills, native adapters and their focused tests. Deliver together in one PR.

## Non-Goals

Do not replace native permissions, remove useful specialist capabilities, delete personal configuration, or rewrite historical execution records.
