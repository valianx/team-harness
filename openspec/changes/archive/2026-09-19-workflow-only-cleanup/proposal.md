## Why

Team Harness still intercepts execution with its own permission and process guards after adopting native general-agent entry. The operator wants the remaining retirement in one reviewable PR while preserving workflow methods and useful session context.

## What Changes

- Retire TH permission decisions in Claude Code and Codex, including the guards already disconnected in Claude and their exclusive launchers, generated assets and tests. **BREAKING:** TH no longer supplies additional deny or ask decisions; the configured native host owns execution policy.
- Preserve session discovery, language, voice, workspace/Obsidian, traces, recovery and observation hooks; keep the shared OpenCode session composer without introducing an installed hook layer.
- Remove the uncalled legacy Claude managed-block installer; keep current setup/update and historical ownership migration.
- Complete the separately authored `simplify-native-pr-review` runtime work in the same PR, using Main for consolidation and specialist recommendations.
- Reconcile specs that required retired guards, regenerate distribution and include completed archives in this PR.

## Capabilities

- `codex-runtime-parity`: remove the TH deny-floor hook chain without modifying native permissions or specialist support.

Hook sources, manifests, launchers and generated copies; setup/update/reload guides; legacy Go helper; focused tests and CI; the affected living specs. PR-review parity remains owned by its existing change. Scope starts from main after #667, not the broad #666 diff.

Deleting workflow methods or the recoverable pipeline control plane; changing native permission settings, models or effort; weakening reviewed-candidate identity or publication authorization; deleting arbitrary user files, historical ledgers or OpenSpec history; claiming identical host security policies or measured token/latency savings.
