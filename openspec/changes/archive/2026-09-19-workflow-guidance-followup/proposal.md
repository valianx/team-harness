## Why

Team Harness should supply a useful way of working on top of each native agent.
GCP still requires nested coordination and exact approval phrases, while inline
review demands activation evidence some hosts cannot expose. Completed proposals
and obsolete release notes also obscure the current workflow.

## What Changes

- Coordinate GCP with the current general agent, retaining inspect, plan,
  validated script, independent review, authorized apply and verification.
- Accept clear authorization for the identified GCP resources and effects without
  repeating it or requiring a magic phrase. Preserve destructive-risk disclosure,
  native permissions, IAM, secret handling and rollback limits.
- Use the native read-only reviewer role without demanding unavailable proof of
  the definition loaded in memory;
  distinguish complete review evidence from Main's delivery decision.
- Reconcile delivered OpenSpec changes with current behavior before archiving;
  retain genuinely unfinished work or explicitly retire superseded intent.
- Keep contract benchmarks as an optional method with workspace evidence,
  replacing the unfinished mandatory three-run baseline ceremony.
- Remove only historical residue with demonstrated replacement or integration.

## Capabilities

### Modified Capabilities

- `native-workflow-entry`: extend current-agent coordination to GCP and use native
  reviewer configuration without an additional loaded-profile activation gate.
- `contract-right-sizing`: optional comparative measurements without mandatory
  pipeline runs or tracked execution-result tables.

## Non-Goals

No cloud changes, runtime permission edits, pipeline state-machine replacement,
bulk deletion of history, loss of skills, model defaults, voice, workspace,
Obsidian, ownership or recovery. This PR is delivered for review, not merged.

## Impact

GCP skill/role/documentation, inline-review instructions and generated runtime
copies; reconciled living specs, archives and proven historical residues.
No new runtime dependency or enforcement layer.
