## Context

See proposal.md. Existing documenter and documentation QA require visuals and page structures even when a short note suffices.

## Decisions

Keep one self-contained canonical skill and use existing skill generation for distribution. Link it from documentation/spec entry points and shared agent guidance. Remove page and diagram quotas in both authorship and QA so review does not restore unnecessary content.

## Risks / Trade-offs

Aggressive shortening could remove requirements or uncertainty. The guide explicitly preserves them, honors requested depth and distinguishes review-only from editing. Adapt editorial principles with MIT attribution; do not import an English detector as a Spanish quality gate.
