# Authoring agents and skills

State the objective, relevant context, useful working approach and evidence of
success. Keep instructions concise enough to read and focused on the role's
actual responsibility.

Use progressive references for specialized detail and native runtime tools for
execution and permissions. Role metadata must parse in the target runtime;
generate distributed copies from their canonical inputs.

A specialist receives a bounded task and returns evidence and recommendations.
The coordinator keeps the wider context and judges the next step. Avoid
duplicating authority through nonces, leases, universal quotas or phrase lists.

Review prose for meaning and practical usability. Test executable helpers,
metadata and projection behavior. A fixed word ceiling or required sentence
does not establish workflow quality.
