# Native specialist coordination

## CC Top-Level Orchestration — the only path

The native general agent coordinates the selected TH flow. It delegates bounded
tasks directly with the host's tools and permissions. TH does not replace the
general agent or dispatch a nested orchestrator.

## Nested-context dispatch — RETIRED protocol, retained provisioning

The historical handoff/takeover protocol and automatic nesting-depth provisioning
are retired. Existing personal settings are preserved; current setup/update does
not require depth two or a restart for that setting.

## Session-Scoped Config Override Protocol

Use the user's explicit session preference ahead of persistent defaults. Read
only relevant fields from the active runtime's configuration and preserve secrets.
Workspace selection belongs to the workspace skill and retains its existing
absolute home across follow-ups. Persist a preference only when requested.

## Routing Table and Escalation Rules

Use the current skill for the user's objective. Spec supports bounded native
delegation; pipeline adds broader coordination when selected. A PR URL selects
a target, not an action. Ask only for a genuinely missing decision.

## Specialist findings

Main assigns ownership, sources and expected outcomes, then checks actual changes
and evidence. Independent reviewers advise from partial context. Main accepts,
adapts or rejects recommendations with reasons and verifies corrections. Native
read-only review capabilities remain distinct from implementation roles.
