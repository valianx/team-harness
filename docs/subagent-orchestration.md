# Coordinating specialists

The current general agent owns the overall objective, integration and user
communication. It can delegate independent questions or tasks with clear scope,
source links, ownership and expected evidence.

Use architects for design uncertainty, implementers for coherent changes,
testers for meaningful independent test work, and QA/security/adversaries to
challenge the candidate. Choose the roles that improve the result rather than
dispatching a fixed chain for every task.

Coordinate shared files and Git operations; preserve other owners' work.
Specialists return findings, changes, verification and limits through native
agent transport. There are no TH leases or authority envelopes.

A reviewer has only part of the context. The coordinator evaluates the actual
finding independently from its proposed remedy, applies worthwhile corrections,
and verifies them. Native read-only review roles remain useful. Reviewer labels
are evidence, not publication permissions.
