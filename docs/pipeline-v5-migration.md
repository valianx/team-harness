# Moving from the control plane to workflow guidance

Current TH workflows use intent, task ownership, evidence and concise progress
notes. The former v5 control-plane writer, specialist leases, nonces, authority
events and gate releases have been retired along with command interception.

Existing workspaces remain readable. Use their plans, task sources, check results
and historical logs to understand prior work, then verify the repository and
available agent results. Continue through the current spec or pipeline skill
without converting history into a new permission schema.

No live configuration reset is part of this migration. Native user permissions,
models and feature settings remain in effect.
