
# Recover

Use [workspace](../workspace/SKILL.md) to reuse the bound file or Page locator
before new defaults. Main coordinates with native tools and
permissions. Reuse authorization for unchanged work and ask only for a missing
decision. Specialists provide evidence and recommendations; Main judges them.

Verify exact remote IDs, parent/Space and source association, or the file identity;
read its plan, tasks, handoff and actual Git state. Inspect old state/logs when they
help explain progress; missing legacy control files do not force closure.
Confirm prior writers stopped before taking overlapping ownership. Continue
authorized work from verified evidence. Missing tools or moved/deleted/inaccessible
context preserves the binding and pending update; independent work may continue
without a replacement home. Start a pipeline only when selected.
