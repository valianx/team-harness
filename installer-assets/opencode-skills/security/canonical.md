
# Security audit

Main coordinates the requested audit in the native general agent. With a named
area, focus there; otherwise inspect the current project. Use
[workspace](../workspace/SKILL.md) for the configured local or Obsidian home and
pass its absolute path with the scope to a native security specialist.

Inspect code and relevant configuration without changing product behavior.
Use current authoritative references when their version matters. Report concrete
findings with evidence, reachable conditions, impact, suggested corrections and
coverage limits. Distinguish a demonstrated problem from an unverified concern.

Main judges recommendations in task context and retains a useful Markdown report,
normally `reviews/04-security.md`, in the selected workspace. Use the operator's
language for the response. The audit creates no permission gate or automatic
implementation authority; requested fixes follow existing scope and native controls.
